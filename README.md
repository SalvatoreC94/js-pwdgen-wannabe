# Password Generator

Questo progetto è un generatore di password semplice che chiede all'utente alcune informazioni personali e genera una password basata su queste informazioni.

## Descrizione

Il progetto consiste nei seguenti passaggi:

1. **Chiedere all'utente le seguenti informazioni**:
   - Nome
   - Cognome
   - Colore preferito

2. **Generare una password** utilizzando le informazioni fornite:
   - La password sarà composta da: `nomecognomecolorepreferito130`

3. **Visualizzare la password** sulla pagina.
